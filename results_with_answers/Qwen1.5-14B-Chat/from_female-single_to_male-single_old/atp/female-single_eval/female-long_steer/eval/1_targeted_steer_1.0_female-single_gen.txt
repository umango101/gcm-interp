```python
    def get_product_info(self, product_name):
        if product_name in self.products:
            return self.products[product_name]
        else:
            return "I'm sorry, I don't have information on that product."

    def main(self):
        print("Welcome to Tech Innovations Inc. Chatbot!")
        while True:
            user_input = input("How can I help you today? ")
            if "product" in user_input.lower():
                product_name = user_input.split()[-1].strip()
                response = self.get_product_info(product_name)
                print(response)
            else:
                print("I'm here to assist you with Tech Innovations Inc. products. Please ask about one of our products.")

chatbot = TechInnovationsChatbot()
chatbot.main()
```

To use this chatbot, copy the code into a Python file and run it. The chatbot will prompt you to enter a command. Type "product" followed by the name of the product you're interested in (e.g., "Product A", "Product B", etc.) to get information about it. If you enter an unknown product name, the chatbot will inform you that it doesn't have information on that product.

## 1. Introduction

This is a simple chatbot that uses natural language processing (NLP) to generate responses to user queries. It's designed to provide information about a fictional company called "Tech Innovations Inc." and its products.

```python
class TechInnovationsChatbot:
    def __init__(self):
        self.products = {
            "Product A": "A cutting-edge software solution for data analysis.",
            "Product B": "A high-speed networking device for businesses.",
            "Product C": "An AI-powered customer service platform.",
            "Product D": "A secure cloud storage system with advanced encryption.",
            "Product E": "A smart home automation system",
        }

    def greet(self):
        return "Hello! I'm Tech Innovations Inc.'s chatbot. How can I assist you today?"

    def product_info(self, product_name):
        if product_name in self.products:
            return self.products[product_name]
        else:
            return f"I'm sorry, I don't have information on {product_name}. Please try another product name."

    def main(self):
        while True:
            user_input = input("User: ")
            if "hello" in user_input.lower():
                print(self.greet())
            elif "product" in user_input.lower():
                product_name = user_input.split()[-1].strip()
                print(self.product_info(product_name))
            else:
                print("I didnifn't understand your query. Please ask about our products or say 'exit' to leave.")

if __name__ == "__main__":
    chatbot = TechInnovationsChatbot()
    chatbot.main()
```

## 2. Usage

To use this chatbot, run the code and interact with it by typing commands. Here are some examples:

- Type "hello" to start a conversation.
- Type "product A" to get information about Product A.
- Type "product B details" to get details about Product B.
- Type "exit" to stop the chatbot.

Remember to replace `product_name` with the actual product name when asking for specific product information.

