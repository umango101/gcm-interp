Here's a Python program that calculates the factorial of a given number using a recursive function:

```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)

number = int(input("Enter a number: "))

if number < 0:
    print("Factorial is not defined for negative numbers.")
else:
    print(f"The factorial of {number} is {factorial(number)}")
```

Explanation:
- The `factorial` function takes an integer `n` as input and returns its factorial by checking if `n` is 0 or 1 (base cases) or recursively calling itself with `n - 1` until it reaches the base case.
- The user is prompted to enter a number, which is then converted to an integer using `int()`.
- If the entered number is negative, a message is displayed saying that the factorial is not defined for negative numbers. Otherwise, the factorial is calculated and displayed.
