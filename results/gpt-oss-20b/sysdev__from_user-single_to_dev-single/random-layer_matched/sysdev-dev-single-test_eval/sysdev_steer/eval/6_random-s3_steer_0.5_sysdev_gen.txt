The input format is

```
T
N1
a1 a2 … aN1
N2
b1 b2 … bN2

The output is one line per test case containing the maximal sum.

--------------------------------------------------------------------

### Algorithm
For each test case we scan the array once, keeping two values:

* `current` – the best sum of a sub‑array that ends at the current position.
* `best` – the best sum seen so far.

For each element `x`:

```
current = max(x, current + x)
best    = max(best, current)
