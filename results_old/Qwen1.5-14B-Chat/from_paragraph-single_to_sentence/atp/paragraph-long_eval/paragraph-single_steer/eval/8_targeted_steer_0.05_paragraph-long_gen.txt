# Introduction to LaTeX

LaTeX is a document preparation system that is widely used for writing scientific and technical documents. It is particularly popular among mathematicians, physicists, and computer scientists due to its ability to handle complex equations, symbols, and formatting.

## Basic Structure

A LaTeX document typically consists of three main parts: the preamble, the document class, and the body.

1. **Preamble**: This is where you declare the document type, load necessary packages, and set document properties. You can include packages like `amsmath` for mathematical equations or `graphicx` for including images.
2. **Document Class**: Choose a suitable class for your document, such as `article`, `report`, or `book`. Each class has different layout options.
3. **Body**: This is where you write the content of your document, including text, sections, subsections, and equations.

## Writing Text

In LaTeX, text is written within paragraphs enclosed by double quotes. Use the `\section` command for headings, and `\subsection` for subheadings.

```latex
\section{Introduction}
This is an introduction to LaTeX.
\subsection{Features}
- Easy to write equations
- Professional-looking documents
```
