\[
dp[i][j] = \text{minimum cost to reach }(i,j)
\]

The first cell is the starting point, so

\[
dp[0][0] = \text{cost of cell }(0,0)
\]

\[
dp[i][j] = \text{cost}(i,j) + \min\bigl(dp[i-1][j],\;dp[i][j-1]\bigr)
\]

The answer is \(dp[N-1][M-1]\).

The recurrence can be evaluated row by row; only the previous row
(and the current row) is needed, so the memory consumption is
\(O(M)\).  The time complexity is \(O(N\!\times\!M)\).
