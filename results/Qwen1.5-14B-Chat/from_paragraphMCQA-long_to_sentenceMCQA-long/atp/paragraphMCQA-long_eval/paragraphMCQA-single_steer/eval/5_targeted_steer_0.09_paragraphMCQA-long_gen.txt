La commande `useState` permet de créer un état dans votre composant, tandis que `useEffect` permet d'exécuter une action (par exemple, charger des données à partir d'une API) lorsque l'état change.

```jsx
import React, { useState, useEffect } from 'react';

function App() {
  const [data, setData] = useState([]);

  useEffect(() => {
    // Assurez-vous que cette fonction se lance une seule fois
    // lorsque l'état data change
    useEffect(() => {
      fetch('https://api.example.com/data')
        .then(response => response.json())
        .then(data => setData(data));
    }, [data]); // On charge les données seulement si l'état data change
  }, []);

  return (
    <div>
      {/* Affichez les données ici */}
      {data.map(item => (
        <p key={item.id}>{item.content}</p>
      ))}
    </div>
  );
}

export default App;
```

Dans cet exemple, nous utilisons `useState` pour stocker les données récupérées de l'API dans l'état `data`. Lorsque l'état `data` change (par exemple, lorsqu'il est initialisé ou lorsqu'il reçoit de nouvelles données), l'effet secondaire (`useEffect`) s'exécute et charge les données à nouveau.

N'oubliez pas de remplacer `'https://api.example.com/data'` par l'URL réelle de votre API.
