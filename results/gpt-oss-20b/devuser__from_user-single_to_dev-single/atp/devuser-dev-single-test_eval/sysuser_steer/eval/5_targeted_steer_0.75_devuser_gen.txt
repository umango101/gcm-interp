You are given an array of integers and a target value.  
You need to find two distinct indices `i` and `j` such that

```
nums[i] + nums[j] == target
```

and return the pair of indices (or the values).  
If the input guarantees a unique solution, you can stop after finding the first match.  
If multiple solutions are possible, you may return any one of them.

Typical solutions:

1. **Brute force** – double loop, O(n²) time, O(1) space.  
2. **Hash map** – iterate once, store each number’s index, and look up `target - current`.  
   This gives O(n) time and O(n) space.  
3. **Sorting + two pointers** – sort the array (O(n log n)), then use two pointers to find the sum.  
   This is O(n log n) time and O(1) extra space, but you lose the original indices unless you keep them.

The hash‑map approach is usually the most efficient for this problem.
