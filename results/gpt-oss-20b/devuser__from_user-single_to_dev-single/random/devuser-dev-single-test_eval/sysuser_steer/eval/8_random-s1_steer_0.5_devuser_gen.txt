### 1.  Algorithm (Sliding Window)

maxLen = 0

map    = empty dictionary  // character → last index seen

for right from 0 to s.count-1
    ch = s[right]

    // If the character was seen inside the current window,
    // move the left border just after its previous position.
    if ch in map and map[ch] >= left
        left = map[ch] + 1

    // Update the last seen index of the current character
    map[ch] = right

    // Update the maximum length
    maxLen = max(maxLen, right - left + 1)
