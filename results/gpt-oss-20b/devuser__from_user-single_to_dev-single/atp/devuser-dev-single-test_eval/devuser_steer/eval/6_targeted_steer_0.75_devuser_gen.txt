seven.assistantfinalThe problem is to find the number of ways to place \(n\) rooks on an \(n\times n\) chessboard such that no two rooks attack each other.  
A rook attacks all squares in its row and column, so the condition is that every row and every column contains at most one rook.  
Thus we must choose a distinct column for each row.

For the first row we can choose any of the \(n\) columns.  
For the second row we must avoid the column already used by the first rook, so we have \(n-1\) choices.  
Continuing in this way, the \(k\)-th row has \(n-k+1\) choices.

Hence the total number of arrangements is

\[
n\cdot (n-1)\cdot (n-2)\cdots 1 = n!
\]

So the answer is \(\boxed{n!}\).
