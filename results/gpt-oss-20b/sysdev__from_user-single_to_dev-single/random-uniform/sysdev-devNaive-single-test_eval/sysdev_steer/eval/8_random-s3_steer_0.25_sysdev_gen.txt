## 1. What is C?

C is a general‑purpose, procedural programming language that was developed in the early 1970s by Dennis Ritchie at Bell Labs. It’s known for its efficiency, low‑level access to memory, and portability across many platforms. C is often used for system programming, embedded systems, and performance‑critical applications.

---

## 2. Why Learn C?

- **Performance**: C gives you fine‑grained control over memory and CPU usage.
- **Portability**: A C program compiled on one platform usually compiles on another with minimal changes.
- **Foundation**: Many modern languages (C++, Java, Python, etc.) borrow concepts from C.
- **Embedded Systems**: C is the de‑facto language for microcontrollers and firmware.
