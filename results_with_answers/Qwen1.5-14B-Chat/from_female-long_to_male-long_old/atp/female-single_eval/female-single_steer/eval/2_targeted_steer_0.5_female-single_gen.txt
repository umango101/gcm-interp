        // 创建一个文件对象
        File file = new File("D:\\test.txt");
        // 判断文件是否存在
        if (!file.exists()) {
            try {
                // 如果不存在则创建文件
                file.createNewFile();
                System.out.println("文件创建成功");
            } catch (IOException e) {
                e.printStackTrace();
            }
        } else {
            System.out.println("文件已存在");
        }
    }
}
```

这段代码首先会检查指定路径（在这个例子中是"D:\test.txt"）的文件是否存在。如果文件不存在，它会尝试创建一个新的文件，并在控制台上打印出"文件创建成功"。如果文件已经存在，它会打印出"文件已存在"。如果在创建文件时发生异常，它会捕获并打印异常堆栈。

请注意，你需要根据你的实际需求修改文件路径。如果你想要创建的是其他类型的文件（如文本文件、二进制文件等），只需更改`file.createNewFile()`为相应的创建方法即可。例如，如果你想创建一个文本文件，可以使用`Files.write(file.toPath(), new byte[0], StandardOpenOption.CREATE);`，但这需要Java 7及以上版本。
