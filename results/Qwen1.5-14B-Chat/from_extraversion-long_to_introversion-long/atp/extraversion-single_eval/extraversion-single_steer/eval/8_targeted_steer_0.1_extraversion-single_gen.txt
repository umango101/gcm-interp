```

code:
```
# Load data
train_data = datasets.MNIST(root='data', train=True, download=True, transform=transforms.ToTensor())
test_data = datasets.MNIST(root='data', train=False, download=True, transform=transforms.ToTensor())
```

code:
```
# Split into train/validation
train_data, val_data = random_split(train_data, test_size=0.2)
```

code:
```
# Create dataloader
train_loader = DataLoader(train_data, batch_size=32, shuffle=True)
val_loader = DataLoader(val_data, batch_size=32, shuffle=True)
```

code:
```
# Define model
class LitModel(LightningModule):
    def __init__(self):
        super().__init__()
        self.l1 = nn.Linear(784, 128)
        self.l2 = nn.Linear(128, 10)

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = self.l2(x)
        return x
    
    def training_step(self, batch, batch_idx):
        x, y = batch
        y_hat = self(x)
        loss = F.cross_entropy(y_hat, y)
        self.log('train_loss', loss)
        return loss

    def validation_step(self, batch, batch_idx):
        x, y = batch
        y_hat = self(x)
        loss = F.cross_entropy(y_hat, y)
        self.log('val_loss', loss)
        return loss

    def configure_optimizers(self):
        self.optim = torch.optim.Adam(self.parameters(), lr=0.001)
```

code:
```
# Build model
model = LitModel()
```

code:
```
# Train model
trainer = Trainer(max_epochs=5, gpus=1 if torch.cuda.is_available() else 0)
trainer.fit(model, train_dataloader=train_loader, val_dataloaders=val_loader)
```

code:
```
# Save model
trainer.save_checkpoint('model.ckpt')
```

```
# Load model
model = LitModel.load_from_checkpoint('model.ckpt')

## Introduction

In this notebook, we will explore the concept of **principal component analysis** (PCA) using the scikit-learn library in Python.

PCA is a dimensionality reduction technique that can be used for data visualization, feature extraction, and noise reduction. It is a linear transformation that projects high-dimensional data onto a lower-dimensional space while preserving as much as possible of the original variance.

The main idea behind PCA is to find a set of orthogonal directions that maximize the variance of the projection of the our data points onto them. These directions are called principal components. The first principal component is the direction of maximum variance, the second one is the direction of maximum variance after the first one has been found, and so on.

In this notebook, we will use PCA to reduce the dimensionality of the digits dataset from MNIST.

# 2. Model

code:
```
# Define the model
import torch.nn as nn
import torch.nn.functional as F

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 500)
        self.fc2 = nn.Linear(500, 10)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x
```

code:
```
# Instantiate the model
model = Net()
```

code:
```
# Define loss function and optimizer
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

# 3. Training

code:
```
# Train the model
num_epochs = 10
for epoch in range(num_epochs):
    for i, (images, labels) in enumerate(train_loader):
        # Forward pass
        outputs = model(images)
        # Compute and print loss
        loss = criterion(outputs, labels)
        print(f'Epoch {epoch+1}/{num_epochs}, Loss: {loss.item():.4f}')
        # Zero the gradients
        optimizer.zero_grad()
        # Backward pass
        loss.backward()
        # Update the weights
        optimizer.step()
```
