tide.assistantfinalThe problem is a classic “two‑sum” search.  
For each element `x` we need to know whether there is a previously seen element `y` such that `x + y = target`.  
A hash map that stores the value of each element and its index gives an `O(1)` lookup, so the whole algorithm runs in `O(n)` time and `O(n)` space.

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // map value -> index
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        throw new IllegalArgumentException("No two sum solution");
    }
}
```

This satisfies the constraints and returns the indices in the required order.
