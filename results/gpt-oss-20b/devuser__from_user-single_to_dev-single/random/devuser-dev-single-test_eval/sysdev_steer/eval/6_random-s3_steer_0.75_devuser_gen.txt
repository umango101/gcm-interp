You need to find the longest contiguous sub‑array whose sum is ≤ k.  
Because all numbers are non‑negative, the window can only grow or shrink from the left, so a single pass with two pointers is enough.

### Algorithm

```
maxLen = 0
sum    = 0
left   = 0

for right = 0 … n-1
        sum += arr[right]

        while sum > k
                sum -= arr[left]
                left += 1

        maxLen = max(maxLen, right - left + 1)
```

* `right` expands the window to the right.  
* If the window sum exceeds `k`, shrink it from the left until it fits.  
* The length of the current window is `right - left + 1`.  
* Keep the maximum length seen.

---

For each test case we read the array, keep a running sum of the best sub‑array ending at the current position, and update the global maximum.  
If all numbers are negative the algorithm still returns the largest (least negative) element.  
The solution runs in O(N) time per test case and uses O(1) extra space.

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    t = data[0]
    idx = 1

        idx += 1

        idx += n

        for x in arr[1:]:
