For every index `i` you can jump to any index `j` such that

i < j ≤ i + arr[i]

### 1.  Dynamic programming formulation  

Let  

```
dp[i] = minimum cost to reach index i from index 0
```

`dp[0] = 0` (we start there).  
For every `i > 0`

```
dp[i] = min{ dp[k] + arr[i] | 0 ≤ k < i  and  k + arr[k] ≥ i }
```

The transition is: from any earlier index `k` that can reach `i`, pay the
cost `arr[i]` to land on `i`.

**Key Insight**:
The number of ways to reach step \(i\) is the sum of the ways to reach step \(i-1\) and step \(i-2\). This recurrence relation is similar to the Fibonacci sequence.

**Dynamic Programming Approach**:
1. Initialize an array `dp` of size \(N+1\) where `dp[i]` represents the number of ways to reach step \(i\).
2. Set base cases: `dp[0] = 1` (one way to stay at the bottom) and `dp[1] = 1` (one way to reach the first step).
3. For each step \(i\) from 2 to \(N\), compute `dp[i] = dp[i-1] + dp[i-2]`.
4. The answer is `dp[N]`.
