```python
def simulate_trial(success_probability):
    return random.random() < success_probability

def simulate_n_trials(n, success_probability):
    return [simulate_trial(success_probability) for _ in range(n)]

# Example usage
n = 10  # number of trials
success_probability = 0.6  # probability of success in each trial

results = simulate_n_trials(n, success_probability)
print(results)
```

This Python script simulates `n` trials with a given `success_probability` for each trial.
