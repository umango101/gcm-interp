```json
    }
  }
}
```

The `type` option determines which deployer to use. Currently, the only supported deployer is `s3`.

## react-native-fetch-blob

React Native fetch plugin for downloading files, reading files and writing files.

## Install

```bash
npm install --save react-native-fetch-blob
```

## Usage

```javascript
import RNFetchBlob from 'react-native-fetch-blob';

RNFetchBlob.fetch('GET', 'http://example.com/file.mp4')
  .then(res => res.blob())
  .then(blob => {
    // do something with the blob
  })
  .catch(err => console.error(err))
```

## API

### fetch(url, options)

- url: string
- options: object (optional)
  - method: string (default: GET)
  - headers: object (default: {})
  - body: string|object (default: null)
  - credentials: string (default: 'same-origin')
  - cache: string (default: 'default')
  - mode: string (default: 'cors')
  - timeout: number (default: 0)
